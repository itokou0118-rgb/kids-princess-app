# だれでしょう？プリンセスクイズ

3歳の女の子むけの、音声で答えるディズニープリンセスあてゲームです。

- 画面にプリンセス風のキャラクターが表示され「この人はだれでしょう？」と読み上げます
  （実在キャラクターのイラストではなく、髪型・髪色・ドレスの色などからオリジナルで描いたイラストです）
- マイクのボタンをタップして名前を声で答えると、正解・不正解を判定して読み上げます
- 不正解のときは正解の名前を教えてくれます
- 音声がうまく聞き取れないときのために、ボタンで選んで答えるモードもあります

## 遊びかた（動かしかた）

マイクをつかう音声にんしき機能は、ブラウザの仕様で「安全なコンテキスト」
（`https://` ではじまるページ、または同じ端末内の `http://localhost`）でないと使えません。

### iPhone・iPadで音声回答を使う場合

iPhoneのSafari（iPhoneでは「Chrome」などのアプリ名でも中身は同じSafariのエンジンです）で
マイクの許可を得るには、`https://` のページとして開く必要があります。
同じWi-Fi内のパソコンからの `http://（IPアドレス）:8000` では、暗号化されていないため
マイクの許可が出ない場合があります。

**GitHub Pages で公開すると、`https://` で誰でも開けるようになります。**
次の手順でONにしてください（このリポジトリはそのため公開リポジトリにしています）。

1. GitHubでこのリポジトリを開き、`Settings` タブへ
2. 左メニューの `Pages` を開く
3. `Build and deployment` の `Source` を `Deploy from a branch` にする
4. `Branch` を `main` / `/ (root)` にして `Save`
5. 数分後、`https://（ユーザー名）.github.io/kids-princess-app/` でアクセスできるようになります

そのURLをiPhoneのSafariで開き、マイクのボタンをタップしたときに出る許可ダイアログで「許可」を選んでください。

### パソコン・Androidタブレットで遊ぶ場合

```bash
cd kids-princess-app
python3 -m http.server 8000
```

同じWi-Fiにつながった端末のブラウザで `http://（パソコンのIPアドレス）:8000` を開いてください
（例: `http://192.168.1.10:8000`）。パソコンだけで遊ぶ場合は `http://localhost:8000` でOKです。
**Google Chrome** が音声にんしきに一番安定して対応しています。

音声にんしきに対応していない・マイクが使えない環境では、自動的にボタンで答えるモードに切り替わります。

## 自分の写真を使いたいとき

お家にある絵本・DVDパッケージ・人形などをご自身で撮影した写真は、`images` フォルダに置くことで
オリジナルイラストの代わりに表示できます。くわしくは [`images/README.md`](images/README.md) を見てください。
（著作権画像をインターネットからダウンロードして使うのはおすすめしません）

## ファイル構成

- `index.html` — 画面のこうぞう
- `style.css` — 見た目（子ども向けの大きなボタン・パステルカラー）
- `princesses.js` — プリンセスのデータと音声の一致判定ロジック
- `portrait.js` — オリジナルのプリンセス風イラストをSVGで描く処理
- `app.js` — ゲームの進行・音声にんしき・音声合成・写真の読み込み処理
- `images/` — 自分で撮った写真を置くためのフォルダ（任意）
