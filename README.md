# だれでしょう？プリンセスクイズ

3歳の女の子むけの、音声で答えるディズニープリンセスあてゲームです。

- 画面にプリンセス風のキャラクターが表示され「この人はだれでしょう？」と読み上げます
  （実在キャラクターのイラストではなく、髪型・髪色・ドレスの色などからオリジナルで描いたイラストです）
- マイクのボタンをタップして名前を声で答えると、正解・不正解を判定して読み上げます
- 不正解のときは正解の名前を教えてくれます
- 音声がうまく聞き取れないときのために、ボタンで選んで答えるモードもあります

## 遊びかた（動かしかた）

音声にんしき機能を使うには「安全なコンテキスト」（`http://localhost` または `https://`）でひらく必要があります。
`index.html` を直接ダブルクリックして開くと、ブラウザによっては音声が使えないことがあるので、
簡単なローカルサーバーを立てて使うのがおすすめです。

```bash
cd kids-princess-app
python3 -m http.server 8000
```

その後、同じWi-Fiにつながったタブレットやスマホのブラウザで、パソコンのIPアドレスを使って
`http://（パソコンのIPアドレス）:8000` を開いてください（例: `http://192.168.1.10:8000`）。

パソコンだけで遊ぶ場合は `http://localhost:8000` でOKです。

対応ブラウザ: 音声にんしき（しゃべって答える機能）は **Google Chrome** が一番安定して動きます。
Chromeで初回にマイクのアクセスをきかれたら「許可」してください。
音声にんしきに対応していないブラウザでは、自動的にボタンで答えるモードが使えます。

## ファイル構成

- `index.html` — 画面のこうぞう
- `style.css` — 見た目（子ども向けの大きなボタン・パステルカラー）
- `princesses.js` — プリンセスのデータと音声の一致判定ロジック
- `portrait.js` — オリジナルのプリンセス風イラストをSVGで描く処理
- `app.js` — ゲームの進行・音声にんしき・音声合成のメイン処理
