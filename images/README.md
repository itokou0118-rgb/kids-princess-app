# 自分の写真を使う方法

このフォルダに、お家にある絵本・DVDパッケージ・人形などをご自身で撮影した写真を置くと、
オリジナルイラストの代わりにその写真がクイズに表示されます。

（著作権のある画像をインターネットからダウンロードして使うのはおすすめしません。
お手持ちの私物を、ご家庭内で個人的に使う範囲でご利用ください。）

## ファイル名

キャラクターごとに、以下のファイル名で保存してください（対応する拡張子: `.jpg` / `.jpeg` / `.png` / `.webp`）。

| ファイル名（例） | キャラクター |
| --- | --- |
| snowwhite.jpg | 白雪姫 |
| cinderella.jpg | シンデレラ |
| aurora.jpg | オーロラ姫 |
| ariel.jpg | アリエル |
| belle.jpg | ベル |
| jasmine.jpg | ジャスミン |
| pocahontas.jpg | ポカホンタス |
| mulan.jpg | ムーラン |
| rapunzel.jpg | ラプンツェル |
| merida.jpg | メリダ |
| tiana.jpg | ティアナ |
| moana.jpg | モアナ |
| elsa.jpg | エルサ |
| anna.jpg | アナ |

写真を用意していないキャラクターは、これまで通りオリジナルイラストが表示されます。
